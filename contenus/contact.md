## Contenu

### Demander un devis d’expertise

Décrivez votre situation. Nous revenons vers vous avec un devis d’expertise adapté — sans engagement de travaux. Justebati ne vend aucun travaux, ne réalise pas les diagnostics obligatoires (DPE, amiante…) ni d’estimation immobilière.

### Coordonnées

- Téléphone : **01 00 00 00 00**
- E-mail : **contact@exemple.fr**

### Formulaire de devis

Champs :

| Champ | Type | Obligatoire |
| --- | --- | --- |
| Prénom | texte | oui |
| Nom | texte | oui |
| Téléphone | tél | oui |
| Code postal | texte | oui |
| Type de bien | liste | oui — Maison / Appartement / Autre |
| Type de mission | liste | oui — voir choix ci-dessous |
| Description | zone de texte | oui |

**Type de mission (6 choix) :**

1. Expertise avant achat
2. Expertise fissures
3. Expertise humidité
4. Malfaçons et réception de travaux
5. Assistance assurance / sinistre
6. Litige avec un artisan

Mention sous le formulaire : en envoyant ce formulaire, vous acceptez que Justebati traite vos données pour répondre à votre demande. Voir la [politique de confidentialité](/politique-de-confidentialite/).

### Après l’envoi

Nous étudions votre message et vous recontactons pour préciser le devis (périmètre, conditions, délais indicatifs). Pour le déroulé type d’une mission : [Comment ça se passe](/comment-ca-se-passe/). Questions générales : [FAQ](/faq/). Qui intervient : [L’expert](/lexpert/).
